# Как помочь проекту

Спасибо, что заглянули! Проект маленький, поэтому правила простые.

## Идеи и баги

* **Баг** → issue по шаблону «🐞 Баг». Самое ценное — «Скопировать диагностику» из панели.
* **Идея** → issue «💡 Идея». Сначала посмотрите [`docs/FEATURES.md`](docs/FEATURES.md):
  возможно, она уже в плане или сознательно отклонена.

## Код

```bash
git clone https://github.com/xxnetme/rutube-tools.git
cd rutube-tools
python3 build.py            # сборка + проверки
```

Зависимостей нет: только Python 3 для сборки и Node (по желанию) для `node --check`.

### Правила

1. **Никакого удалённого кода и `eval`** — расширение должно проходить ревью AMO.
2. **Новые разрешения** — только с объяснением в PR и правкой `docs/PRIVACY.md`.
3. **Тексты интерфейса** — через `src/lib/i18n.js` (RU и EN обязательно).
4. **Логика скачивания** — в `src/lib/engine.js`, протокол прогресса — без готовых строк,
   локализация в `content-panel.js`.
5. **Проверка на живом RuTube** обязательна: сборка проходит — ещё не значит, что работает.

### Стиль

* ES5-совместимый JS в content-скриптах (без сборщика), `async/await` — можно.
* Отступы 2 пробела, одинарные кавычки, точки с запятой.
* Функции с побочными эффектами — именованные, чтобы читались в стеке.

## Перед PR

- [ ] `python3 build.py` без ошибок
- [ ] Проверено в Firefox и Chromium
- [ ] Обновлён `docs/CHANGELOG.md` (одна строка, понятная не-технарю)
