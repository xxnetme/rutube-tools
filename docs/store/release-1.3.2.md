Подготовка к публикации в магазинах дополнений. Функции расширения не менялись.

**Манифесты**
- `gecko.id` — `rutube-tools@xxnetme.github.io`: свой домен вместо стороннего. После первой публикации в AMO идентификатор менять нельзя, поэтому сделано заранее.
- Минимальный Firefox — 140: с этой версии поддерживается обязательное для новых дополнений поле `data_collection_permissions`.
- Убрано неиспользуемое разрешение `optional_host_permissions: *://*/*` — широкие разрешения на ревью просят обосновать.
- Версия поднята до 1.3.2 в обоих манифестах.

**Для карточек магазинов**
- Публичная политика конфиденциальности: https://xxnetme.github.io/rutube-tools/privacy.html
- Промо-плитки: `promo-marquee.png` (1400×560) и `promo-small.png` (440×280)
- Текст карточки для AMO без HTML, обоснование каждого разрешения, заметки для ревьюеров Chrome/Edge
- Пошаговая инструкция по четырём каналам: `docs/PUBLISH.md`

**Проверено**
- `addons-linter`: 0 ошибок, 1 предупреждение (версия для Android)
- Сборка 1.3.2 грузится в Chromium: фон, попап и панель на странице видео работают, ошибок в консоли нет

**Установка**
- Firefox: `rutube-tools-firefox.xpi` → `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение»
- Chrome/Edge: `rutube-tools-chromium.zip` → распаковать → `chrome://extensions` → «Загрузить распакованное»
