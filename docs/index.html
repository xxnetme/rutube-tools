01

Возможности

01

Скачивание в MP4

1080p…144p. Фрагменты потока качаются параллельно и собираются в обычный MP4 прямо в браузере — без ffmpeg и внешних программ.

02

Фрагмент по таймкодам

«С 12:30 по 12:45» — не нужно качать час ради двух минут. Время можно взять прямо из плеера, фактические границы показываются до старта.

03

Плейлисты

Очередь на странице плейлиста: диапазон серий, пауза между видео, счётчик готовых файлов и отчёт об ошибках.

04

Покадровая перемотка

Шаг по кадрам с номером кадра и таймкодом, переход на кадр по номеру, петля A/B, сохранение кадра в PNG и раскадровка серией.

05

Субтитры, обложка, главы

SRT, включая авто-субтитры RuTube, постер в JPG, метки глав из cuepoints и мини-плеер поверх других окон.

06

Устойчивость к обрывам

Каждое качество RuTube отдаёт с двух серверов. При обрыве расширение перечитывает плейлист с резервного и продолжает с того же фрагмента.

Установка

01

Скачать файл расширения

Для Firefox — .xpi, для Chromium — .zip.

1 файл
02

Открыть страницу дополнений

Firefox: about:debugging#/runtime/this-firefox · Chrome: chrome://extensions

без перезапуска
03

Загрузить

Firefox — «Загрузить временное дополнение» и выбрать .xpi. Chromium — «Режим разработчика» и «Загрузить распакованное» из папки.

≈ 1 минута

В Firefox временное дополнение действует до перезапуска браузера. Для постоянной установки нужна подпись на addons.mozilla.org — процедура описана в docs/PUBLISH.md.

03

Интерфейс

Четыре вкладки в одной панели, которая не спорит с оформлением RuTube.

05

Чего расширение не делает

Не обходит DRM

Платные и защищённые видео не скачиваются. Это осознанное ограничение.

Не записывает эфиры

Прямые трансляции не поддерживаются.

Не собирает данные

Нет аналитики, аккаунтов и серверов. Запросы только к RuTube и его CDN.

Не перекодирует

Файл скачивается в выбранном качестве как есть.
