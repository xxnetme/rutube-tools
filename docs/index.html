Что умеет

Четыре вкладки в одной аккуратной панели — и ноль настроек, чтобы начать.

🎬 MP4 целиком и фрагментом

«С 12:30 по 12:45» — точность до фрагмента потока. Склейка в обычный MP4 прямо в браузере.

📚 Плейлисты

Очередь с паузой, диапазоном серий и отчётом об ошибках по каждому видео.

🖼️ Кадры в PNG

Шаг по кадрам, сохранение кадра, раскадровка серией и A/B-петля.

💬 Субтитры и обложка

.srt (включая авто-субтитры), .jpg обложка, главы, мини-плеер.

🛰️ Зеркала CDN

RuTube отдаёт каждое качество с двух серверов — расширение само переходит на рабочее.

🔐 Приватность

Ни аналитики, ни рекламы. Запросы только к RuTube, без cookie.

Установка

Нужна одна минута.

Firefox — скачать файлrutube-tools-firefox.xpi
Открыть страницу дополненийВ адресной строке: about:debugging#/runtime/this-firefox
«Загрузить временное дополнение…»Выбрать скачанный .xpi — всё, кнопка MP4 появится на странице видео.
Chrome / Edge / ЯндексСкачать zip, распаковать, открыть chrome://extensions, включить «Режим разработчика» → «Загрузить распакованное».
⚠️
Временное дополнение в Firefox живёт до перезапуска браузера. Для постоянной установки нужна подпись на addons.mozilla.org — инструкция в docs/PUBLISH.md.
