Политика конфиденциальности — RuTube Tools

Последнее обновление: 29.10.2026

Версия расширения: 1.3.2

Коротко

Расширение RuTube Tools не собирает, не хранит и не передаёт ваши персональные данные. Вся работа происходит локально в вашем браузере.

Чего расширение не делает

  • Не отправляет аналитику, телеметрию и «статистику использования».
  • Не содержит рекламы, трекеров и сторонних скриптов.
  • Не читает содержимое других сайтов: скрипт работает только на rutube.ru. Разрешений на «все сайты» в манифесте нет.
  • Не имеет доступа к вашим паролям, cookie-файлам аутентификации и переписке. Запросы к API RuTube идут без передачи cookie (credentials: 'omit').
  • Не продаёт и не передаёт данные третьим лицам, потому что данных просто нет.

Сторонний код

В комплект входит библиотека mux.js (Apache License 2.0). Она работает локально и не отправляет данные наружу.

Дети

Расширение не предназначено для детей и не собирает данные ни о ком.
