# Политика конфиденциальности — RuTube Tools

**Последнее обновление:** 29.10.2026
**Версия расширения:** 1.3.0

## Коротко

Расширение RuTube Tools **не собирает, не хранит и не передаёт** ваши персональные данные.
Вся работа происходит локально в вашем браузере.

## Какие данные обрабатываются

| Что | Где | Зачем | Куда уходит |
|---|---|---|---|
| Адрес `.m3u8`-плейлиста и фрагменты видео | на вашем устройстве | чтобы скачать выбранное видео и собрать MP4 | только на серверы RuTube / его CDN (`rutube.ru`, `*.rtbcdn.ru`), откуда вы и так смотрите видео |
| Название видео, длительность, список качеств | на вашем устройстве | показать качества и назвать файл | никуда |
| Настройки (качество, частота кадров, размер частей, клавиши) | `storage.local` браузера | сохранить ваш выбор между сессиями | никуда, остаётся на устройстве |
| Сохранённые файлы | папка «Загрузки» | это и есть результат работы | никуда |
| Позиция просмотра (таймкод) | `storage.local` | кнопка «Продолжить с 12:34» | никуда |
| Субтитры и обложка | запрашиваются у RuTube по кнопке | скачать .srt / .jpg | только на серверы RuTube |
| Диагностика ошибки | формируется локально по кнопке | чтобы вы могли отправить её разработчику | никуда, пока вы сами её не скопируете |

## Чего расширение НЕ делает

* Не отправляет аналитику, телеметрию и «статистику использования».
* Не содержит рекламы, трекеров и сторонних скриптов.
* Не читает содержимое других сайтов: скрипт работает только на `rutube.ru`.
  Разрешение `optional_host_permissions` не запрашивается автоматически — только если вы
  сами решите им воспользоваться в будущем.
* Не имеет доступа к вашим паролям, cookie-файлам аутентификации и переписке.
  Запросы к API RuTube идут **без** передачи cookie (`credentials: 'omit'`).
* Не продаёт и не передаёт данные третьим лицам — потому что данных просто нет.

## Разрешения и зачем они нужны

| Разрешение | Назначение |
|---|---|
| `storage` | сохранение ваших настроек на устройстве |
| `downloads` | сохранение готового MP4/PNG в папку «Загрузки» |
| `offscreen` (только Chromium) | сборка файла в фоновом документе — в служебном скрипте нет `URL.createObjectURL` |
| `*://rutube.ru/*`, `*://*.rutube.ru/*` | показать кнопку и панель на странице видео |
| `*://*.rtbcdn.ru/*`, `*://*.rtbcdn.net/*` | загрузка фрагментов видео с CDN RuTube |

## Сторонний код

В комплект входит библиотека [mux.js](https://github.com/videojs/mux.js) (Apache License 2.0),
она работает локально и не отправляет данные наружу.

## Дети

Расширение не предназначено для детей и не собирает данные ни о ком.

## Изменения

Если политика изменится, обновлённая версия будет опубликована вместе с новой версией
расширения, а дата вверху — изменена.
